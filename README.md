# 출근버스 (CommuteBus)

출근버스 탑승을 자동으로 기록하고, 배차별로 실제 도착 시각과 집에서 나갈 시각을 예측해 알림을 주는 안드로이드 앱.

## 설치
1. Android Studio에서 이 폴더 열기 (Gradle 동기화는 자동)
2. 휴대폰 개발자 옵션 → USB 디버깅 켜고 연결 → ▶ Run
   (Android 10 이상, Google Play 서비스 필요)

## 처음 설정
1. 설정 → 배차 시각 확인 (기본 06:00~09:15 15분 간격 + 09:20)
2. 설정 → 집→정류장 걷는 시간
3. 권한 설정 → 위치 '항상 허용', 신체 활동, 알림
4. 배터리 예외 → 허용 (삼성 기기는 필수)
5. 정류장에 서서 "지금 서 있는 곳을 정류장으로"
6. 자동 기록 켜기
7. 주로 타는 버스를 고르고 "주로 타는 버스로" → 매일 출발 알림

추가로 휴대폰 설정 → 위치 → 위치 서비스 → Google 위치 정확도가 켜져 있어야 지오펜스가 잘 동작함.

## 동작
- 감지: 정류장 지오펜스 진입 → 이탈, 그리고 차량 탑승 인식(IN_VEHICLE)이 10분 안에 함께 일어나면 탑승으로 기록.
  출근 시간대·평일에만. 같은 아침 20분 안 중복은 무시.
- 기록 시각: 위치 측정 시각 / 활동 인식 발생 시각 중 이른 쪽 (알림 전달이 늦어도 시각은 정확).
- 예측: 배차마다 최근 40개 기록의 지연(실제-예정) 분포.
  같은 요일 기록 4개 이상이면 요일별.
  예상 도착 = 예정 + 지연 중앙값
  집 출발 = 예정 + 지연 하위 분위수(확실도: 10%/25%/50%) − 걷는 시간
- 알림: 주로 타는 버스의 집 출발 시각 N분 전에 정확한 알람으로 알림. 재부팅 후 자동 재등록.

## 파일
- Store.kt — 기록·설정 저장 (SharedPreferences/JSON)
- Predictor.kt — 배차 매칭, 분위수 예측
- Tracker.kt — 지오펜스·활동 인식 등록, 탑승 판정, 리시버
- Notifier.kt — 탑승 기록 알림, 출발 알림 예약
- MainActivity.kt — 화면
